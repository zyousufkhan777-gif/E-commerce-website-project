# 🛒 E-Commerce Website

A modern full-stack E-Commerce web application built with React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

https://e-commerce-website-project-b6ac-isw3zzd4m-yousuf-s-projects3.vercel.app/

## ✨ Features

- User Authentication
- Product Search
- Shopping Cart
- Responsive Design
- Admin Dashboard
- Secure Backend API

## 🛠 Tech Stack

### Frontend
- React
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## 📁 Project Structure

```
frontend/
backend/
```

## ⚙️ Installation

```bash
git clone https://github.com/zyousufkhan777-gif/E-commerce-website-project.git
```
